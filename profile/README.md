# AK²Lab

Webサイト、Webアプリ、業務システムを、画面のデザインと、更新の仕組み、JavaScriptによる画面の動きまで含めて制作しています。

## 制作事例

サイト、業務の仕組み、画面の動きから、一つずつ置いています。

- [次葉文化アーカイブ](https://github.com/ak2lab/tsugiha)は、スクロールを時間軸にした3Dのブランドサイトです。[デモ](https://tsugiha.ak2lab.com/)
- 管理画面から静的HTMLを出す仕組みは、[静的サイト生成CMS](https://github.com/ak2lab/cms)です。[デモ](https://cms.ak2lab.com/)
- 画面の動きの実験として、[ブラウザ版テトリス](https://github.com/ak2lab/tetris)を置いています。[デモ](https://game.ak2lab.com/tetris/)

すべての事例は [制作事例の一覧](https://ak2lab.github.io/) にまとめています。

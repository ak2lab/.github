# AK²Lab

Webサイト・Webアプリ・業務システムを制作しています。画面のデザインから実装、日々使う仕組みまで、制作物と技術を紹介します。

## 制作と技術

- Webサイトのデザインと実装
- 業務システムとWebアプリの開発
- 静的サイト生成と更新の仕組み
- JavaScriptによるインタラクションと立体表現

## まず見る

- [次葉文化アーカイブ](https://github.com/ak2lab/tsugiha)：スクロールが時間軸になる3Dのブランドサイト。[デモ](https://tsugiha.ak2lab.com/)
- [AK²Engine](https://github.com/ak2lab/ak2-engine)：YAMLとCanvas背景でページを組む静的サイトの制作基盤。[デモ](https://ak2engine.ak2lab.com/)
- [静的サイト生成CMS](https://github.com/ak2lab/cms)：管理画面から静的HTMLを生成する制作基盤。[デモ](https://cms.ak2lab.com/)
- [ブラウザ版テトリス](https://github.com/ak2lab/tetris)：HTML5 Canvasで動くブラウザ版。[デモ](https://game.ak2lab.com/tetris/)

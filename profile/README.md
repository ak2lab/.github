# AK²Lab

Webサイト・Webアプリ・業務システムを制作しています。画面のデザインから実装、日々使う仕組みまで、制作物と技術を紹介します。

## 制作と技術

- Webサイトのデザインと実装
- 業務システムとWebアプリの開発
- 静的サイト生成と更新の仕組み
- JavaScriptによるインタラクションと立体表現

## 公開リポジトリ

- [AK²Engine](https://github.com/ak2lab/ak2-engine): Eleventyを土台に、YAMLでページ構成とCanvas背景を組み立てる、自作の静的サイト制作基盤。
- [ブラウザ版テトリス](https://github.com/ak2lab/tetris): SEGAアーケード版の操作感を意識した、HTML5 Canvasだけで動くブラウザ版テトリス。キー設定とハイスコアに対応。
